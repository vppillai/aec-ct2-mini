# aectest release notes

## 0.2.0 (2026-10-21)

The first public release.

- Web UI: the pages Cable, Test a cable, Advanced, Records, Help and Settings.
- Cable page: read the cable identity, the power class, the applications and the test features.
- Test a cable: the technician flow with a step card, a verdict card and a record of each run.
- Advanced page: the pair PRBS tests, the feature matrix, CDB queries and the cable database.
- Firmware update of a module over CDB: plan, update, run and commit as separate steps.
- Cable passport: the plate of a cable as a record file.
- CMIS decode of every advertised page, with a lane view.
- The command line `aectest` with the same commands plus lane integrity, the SI sweep and the flag matrix, and `--dry-run` with a fake module.
